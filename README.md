# W3Schools Offline Mirror (Archived)

A fully offline, highly compressed mirror of the popular W3Schools web development tutorials and documentation repository (originally by `ja7ad`). 

> 📊 **Archive Compression Stats**
> * **Original Compressed / ZIP Size:** ~600 MB
> * **Highly Compressed (7z) Size:** ~100 MB (~83% size reduction!)

Created to help students and developers access complete web dev documentation (HTML, CSS, JavaScript, PHP, SQL, and more) without needing an active internet connection.

## 📦 Download & Extraction

Because this repository is heavily compressed, follow these steps to get it running locally:

1. Download the archive (`.7z` or `.zip`) from the **Releases** section.
2. Extract the archive using [7-Zip](https://www.7-zip.org/) or WinRAR.
3. Open the extracted folder and double-click `index.html` to launch it in your web browser.

## 🚀 Features
- 100% offline access to tutorials, references, and code examples.
- Highly compressed archive size for fast downloading.
- Preserved structure for seamless browsing.
